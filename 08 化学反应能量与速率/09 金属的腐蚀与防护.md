# 09 · 金属的腐蚀与防护 <Badge type="warning" text="整理中" />

## 金属腐蚀的概述

1. **定义**：金属或合金与周围接触到的气体或液体发生**氧化还原反应**而引起损耗的现象。
2. **本质**：金属原子失去电子被氧化：$\ce{M - ne^- -> M^{n+}}$。
3. **危害**：全球每年因腐蚀报废的金属设备相当于年产量的 $20\%\sim40\%$。

## 腐蚀的分类

| 类别       | 反应条件                       | 是否有电流 | 举例                         |
| ---------- | ------------------------------ | ---------- | ---------------------------- |
| 化学腐蚀   | 金属与氧化剂**直接**反应       | 无         | 铁与氯气反应、钢管被硫酸腐蚀 |
| 电化学腐蚀 | 不纯金属与电解质溶液构成原电池 | **有**     | 钢铁在潮湿空气中生锈         |

> **注意**
> 两者常同时发生，但**电化学腐蚀更普遍**、危害更大（速率更快）。

## 钢铁的电化学腐蚀

钢铁是铁与碳的合金，在潮湿空气中表面形成一层水膜（溶有 $\ce{CO2}$、$\ce{SO2}$ 等成为电解质溶液），构成无数微小原电池：铁作负极，碳作正极。

### 析氢腐蚀（水膜酸性较强时）

- **负极（Fe）**：$\ce{Fe - 2e^- = Fe^{2+}}$
- **正极（C）**：$\ce{2H+ + 2e^- = H2 ^}$
- 后续：$\ce{Fe^{2+} + 2OH^- = Fe(OH)2 v}$，再被氧化为 $\ce{Fe(OH)3}$

### 吸氧腐蚀（水膜酸性很弱或呈中性，**更普遍**）

- **负极（Fe）**：$\ce{2Fe - 4e^- = 2Fe^{2+}}$
- **正极（C）**：$\ce{O2 + 2H2O + 4e^- = 4OH^-}$
- 后续：$\ce{Fe(OH)2}$ 被氧气继续氧化

$$
\ce{4Fe(OH)2 + O2 + 2H2O = 4Fe(OH)3}
$$

$\ce{Fe(OH)3}$ 部分失水生成铁锈（主要成分 $\ce{Fe2O3\cdot xH2O}$）。

> **提示**
> 判断要点：正极反应看水膜酸碱性——酸性较强放 $\ce{H2}$（析氢腐蚀），中性/弱酸性吸 $\ce{O2}$（吸氧腐蚀）。吸氧腐蚀中氧气的**浓度越大**、温度越高、电解质离子浓度越大，腐蚀越快。

## 影响腐蚀速率的因素

1. 金属活动性越强，越易腐蚀；
2. 与金属接触的电解质溶液浓度越大、氧气浓度越高，腐蚀越快；
3. 温度越高，腐蚀越快；
4. 构成原电池时，作**负极**的金属加速腐蚀（如镀锌铁破损后锌先腐蚀，铁被保护；镀锡铁破损后铁作负极，反而**加速**腐蚀）；
5. 干燥、隔绝空气的环境中腐蚀极慢（如干燥空气中铁器长期不锈）。

## 金属的防护

### 改变金属的内部结构

制成合金，如不锈钢（加 $\ce{Cr}$、$\ce{Ni}$），增强抗腐蚀能力。

### 覆盖保护层（隔绝空气和水）

1. 涂油漆、搪瓷、塑料；
2. 电镀耐腐蚀金属（镀铬、镀镍）；
3. 形成致密氧化膜（铝表面氧化、发蓝处理）。

### 电化学保护法

| 方法                               | 原理                                       | 适用               | 示例                         |
| ---------------------------------- | ------------------------------------------ | ------------------ | ---------------------------- |
| 牺牲阳极的阴极保护法（原电池原理） | 被保护金属作**正极**，活泼金属作负极被消耗 | 海水中船舶、锅炉   | 船体焊接锌块，锌溶解保护铁   |
| 外加电流的阴极保护法（电解原理）   | 被保护金属与电源**负极**相连作阴极         | 大型设施、地下管道 | 钢闸门接电源负极，废铁作阳极 |

> **重点**
> 两种方法的共同点：都是让被保护的金属成为**阴极**（发生还原反应、不被氧化）；区别在于电子来源——牺牲阳极法中电子来自活泼金属的氧化（原电池，被保护金属为正极），外加电流法中电子来自外接电源（电解池，被保护金属接电源负极）。

## 注意事项

1. 吸氧腐蚀正极反应式 $\ce{O2 + 2H2O + 4e^- = 4OH^-}$ 是电化学考频最高的电极反应式之一，务必熟记；
2. 镀层破损后：镀**锌**铁仍受保护（Zn 活泼），镀**锡**铁加速腐蚀（Fe 作负极）；
3. 牺牲阳极法消耗的是**更活泼的辅助金属**，不是被保护金属；
4. 铁锈是 $\ce{Fe2O3\cdot xH2O}$，生成过程：$\ce{Fe \to Fe^{2+} \to Fe(OH)2 \to Fe(OH)3 \to Fe2O3\cdot xH2O}$，不要写成一步反应。

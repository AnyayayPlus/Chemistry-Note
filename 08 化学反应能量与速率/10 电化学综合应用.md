# 10 · 电化学综合应用 <Badge type="warning" text="整理中" />

## 电化学装置的判断

| 判断依据         | 原电池                    | 电解池                           |
| ---------------- | ------------------------- | -------------------------------- |
| 能量转化         | 化学能 → 电能（自发反应） | 电能 → 化学能（非自发反应）      |
| 电极名称         | 正极（+）、负极（−）      | 阳极、阴极                       |
| 电极反应         | 负极氧化、正极还原        | 阳极氧化、阴极还原               |
| 电子流向         | 负极 → 导线 → 正极        | 电源负极 → 阴极，阳极 → 电源正极 |
| 电解质中离子移动 | 阳离子→正极，阴离子→负极  | 阳离子→阴极，阴离子→阳极         |

**记忆口诀**：正阳氧，负阴还——阳极发生氧化反应，阴极发生还原反应（原电池的负极同样发生氧化）。

判断步骤：先看有无外接电源（有则为电解池/电镀池），再看电极材料与反应自发性；复合装置（原电池带电解池）先分析**自发反应的原电池**，再确定电流方向分析电解部分。

## 离子交换膜电解

### 交换膜的类型与作用

离子交换膜只允许特定离子通过：

1. **阳离子交换膜**：只允许阳离子（$\ce{Na+}$、$\ce{K+}$、$\ce{H+}$ 等）通过；
2. **阴离子交换膜**：只允许阴离子（$\ce{Cl^-}$、$\ce{OH^-}$ 等）通过；
3. **双极膜**：将水解离为 $\ce{H+}$ 与 $\ce{OH^-}$，分别向两侧供给。

设置交换膜的目的：**隔离两极产物**、防止副反应、获得纯净产物。

### 典型应用一：氯碱工业（阳离子交换膜）

阳离子交换膜法电解饱和食盐水，膜只允许 $\ce{Na+}$ 通过：

- **阳极室**：$\ce{2Cl^- - 2e^- = Cl2 ^}$（氯气、淡盐水流出）
- **阴极室**：$\ce{2H2O + 2e^- = H2 ^ + 2OH^-}$，$\ce{Na+}$ 迁入阴极室与 $\ce{OH^-}$ 组成 $\ce{NaOH}$（氢气、碱液流出）
- **总反应**：$\ce{2NaCl + 2H2O \xlongequal{电解} 2NaOH + H2 ^ + Cl2 ^}$

膜的三个作用：阻止 $\ce{H2}$ 与 $\ce{Cl2}$ 混合爆炸；阻止 $\ce{Cl2}$ 与 $\ce{NaOH}$ 反应变质；只允许 $\ce{Na+}$ 通过保证烧碱纯度。

### 典型应用二：三室电解 $\ce{Na2SO4}$ 溶液制备硫酸和烧碱

以双阳膜（或阳膜/阴膜组合）分隔三室：

- 阴极室：$\ce{2H2O + 2e^- = H2 ^ + 2OH^-}$，得 $\ce{NaOH}$ 溶液；
- 阳极室：$\ce{2H2O - 4e^- = O2 ^ + 4H+}$，得硫酸溶液；
- 中间室 $\ce{Na2SO4}$ 逐渐变稀，$\ce{Na+}$、$\ce{SO4^{2-}}$ 分别迁入两侧。

### 其他高频情境

- 电解法制备 $\ce{LiOH}$：锂离子交换膜允许 $\ce{Li+}$ 由正极区迁向阴极区；
- 电解 $\ce{CO2}$ 制备 $\ce{HCOOH}$、$\ce{CO}$ 等燃料（阴极还原，常配质子交换膜或阴离子交换膜，注意 $\ce{H+}$ 与 $\ce{HCO3^-}$ 的迁移方向）；
- 电解海水制氢：膜隔离 $\ce{Cl2}$、提高产品纯度。

> **重点**
> 膜问题的通用解法：先写两极反应，再按"阳离子奔阴极、阴离子奔阳极"判断迁移方向，最后检查膜两侧电荷守恒与产物分离需求，反推膜的种类。

## 燃料电池的电极反应式书写

### 书写步骤

1. 写出负极燃料失电子的氧化产物（碱性环境 $\ce{CO2}$ 会转化为 $\ce{CO3^{2-}}$）；
2. 写出正极氧化剂得电子的还原产物；
3. 用介质离子（$\ce{H+}$、$\ce{OH^-}$、$\ce{CO3^{2-}}$）配平电荷，最后配平原子。

### 氢氧燃料电池

| 介质 | 负极反应                        | 正极反应                        |
| ---- | ------------------------------- | ------------------------------- |
| 酸性 | $\ce{H2 - 2e^- = 2H+}$          | $\ce{O2 + 4H+ + 4e^- = 2H2O}$   |
| 碱性 | $\ce{H2 - 2e^- + 2OH^- = 2H2O}$ | $\ce{O2 + 2H2O + 4e^- = 4OH^-}$ |

总反应均为 $\ce{2H2 + O2 = 2H2O}$。

### 甲烷燃料电池（碱性介质，$\ce{KOH}$ 溶液）

- 负极：$\ce{CH4 - 8e^- + 10OH^- = CO3^{2-} + 7H2O}$
- 正极：$\ce{2O2 + 4H2O + 8e^- = 8OH^-}$

> **注意**
> 熔融碳酸盐燃料电池（MCFC）以 $\ce{CO3^{2-}}$ 为迁移离子，介质中**无 $\ce{OH^-}$**，电极反应与上述碱性水溶液不同，不可套用。

### 甲醇燃料电池（酸性介质）

- 负极：$\ce{CH3OH - 6e^- + H2O = CO2 + 6H+}$
- 正极：$\ce{3O2 + 12H+ + 12e^- = 6H2O}$

## 二次电池

### 铅蓄电池

总反应：$\ce{Pb + PbO2 + 2H2SO4 \xrightleftharpoons[充电]{放电} 2PbSO4 + 2H2O}$

| 阶段 | 负极（−）                                 | 正极（+）                                                | 说明                   |
| ---- | ----------------------------------------- | -------------------------------------------------------- | ---------------------- |
| 放电 | $\ce{Pb - 2e^- + SO4^{2-} = PbSO4}$       | $\ce{PbO2 + 2e^- + 4H+ + SO4^{2-} = PbSO4 + 2H2O}$       | 相当于原电池           |
| 充电 | 阴极：$\ce{PbSO4 + 2e^- = Pb + SO4^{2-}}$ | 阳极：$\ce{PbSO4 - 2e^- + 2H2O = PbO2 + 4H+ + SO4^{2-}}$ | 接外电源，相当于电解池 |

放电时 $\ce{H2SO4}$ 被消耗，密度减小，可用**测定电解液密度**判断充电/放电程度。

### 锂离子电池

以 $\ce{LiCoO2}$ 为正极、石墨为负极（ $\ce{LiFePO4}$ 等常见）：

- 放电负极：$\ce{Li_{x}C6 - xe^- = xLi+ + 6C}$
- 放电正极：$\ce{Li1-xCoO2 + xLi+ + xe^- = LiCoO2}$

特点：比能量高、无记忆效应；**电解质不能含水**（$\ce{Li}$ 及 $\ce{Li+}$ 体系遇水会副反应），常用非水有机溶剂或固态电解质。

> **提示**
> 二次电池的口诀："充电时，原负极接电源负极作阴极（复原），原正极接电源正极作阳极（复原）"。书写充电反应式时可直接把放电反应逆写。

## 电化学计算

### 核心守恒：电子守恒

1. 串联电路中，各电极转移的电子数**相等**；
2. 两极产物的物质的量之比 = 电极反应式中电子数之比的倒数。

**例**：电解饱和食盐水，电路中通过 $0.4\ \mathrm{mol}$ 电子，求两极产物。

- 阳极：$\ce{2Cl^- - 2e^- = Cl2 ^}$，$n(\ce{Cl2})=0.2\ \mathrm{mol}$；
- 阴极：$\ce{2H2O + 2e^- = H2 ^ + 2OH^-}$，$n(\ce{H2})=0.2\ \mathrm{mol}$，$n(\ce{NaOH})=0.4\ \mathrm{mol}$。

### 常用计算模型

1. **析出金属/气体质量**：$n(\text{产物})=\dfrac{n(\ce{e^-})}{\text{电极反应中电子数}}$；
2. **溶液 pH 变化**：由电极反应生成的 $\ce{H+}$ / $\ce{OH^-}$ 物质的量除以溶液体积；
3. **串联多池**：以同一电子数为纽带，逐池列电极反应计算；
4. **法拉第常数估算**：$Q=n(\ce{e^-})\times N_{A}\times 1.6\times10^{-19}\ \mathrm{C}$（题目一般给出 $F$，按 $Q=n(\ce{e^-})F$ 计算）。

## 注意事项

1. 电解池的"阳极接电源正极"，与原电池的"正极"不要混淆；
2. 活性阳极（除 $\ce{Pt}$、$\ce{Au}$、石墨外的金属）**优先**溶解，溶液中阴离子不放电；
3. 燃料电池在碱性介质中，负极产物 $\ce{CO2}$ 必须写成 $\ce{CO3^{2-}}$，否则电荷不守恒；
4. 膜题先看"膜只允许某类离子通过"这一条件，产物纯净性、气体隔爆都是膜带来的结果；
5. 计算题先统一"电子数"这一纽带，再按电极反应式比例换算，切忌用总反应直接配比（电解类尤其如此）。
